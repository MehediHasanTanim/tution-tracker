# Installing the app without Google Play

For tutors who cannot use Play (no Google account, or a phone without it). The APK
is built by `tool/release.sh`: pick the file for the phone's CPU
(`app-arm64-v8a-prod-release.apk` for almost every phone made since 2016;
`app-armeabi-v7a-prod-release.apk` for older or very cheap ones).

## English

1. Send the APK to the phone (WhatsApp, Telegram, Drive, cable).
2. Open it. If Android says "Install unknown apps", tap **Settings**, allow it for
   the app you opened it from (for example WhatsApp), then go back and tap
   **Install**.
3. Open **Tuition Khata**. Choose your language. Nothing else is needed: no sign-up,
   no internet.
4. Afterwards you may switch "Install unknown apps" off again.

## বাংলা

১. APK ফাইলটি ফোনে পাঠান (WhatsApp, Telegram, ড্রাইভ বা তার দিয়ে)।
২. ফাইলটি খুলুন। “অজানা অ্যাপ ইনস্টল” বললে **সেটিংস** চাপুন, যে অ্যাপ থেকে খুলেছেন (যেমন WhatsApp) তার জন্য অনুমতি দিন, ফিরে এসে **ইনস্টল** চাপুন।
৩. **টিউশন খাতা** খুলুন, ভাষা বেছে নিন। আর কিছু লাগে না: সাইন-আপ নেই, ইন্টারনেট লাগে না।
৪. ইনস্টলের পর “অজানা অ্যাপ ইনস্টল” আবার বন্ধ করে দিতে পারেন।

## Updating

Install the newer APK over the old one; the records stay. **Do not** uninstall
first. If you ever must (or switch between the Play version and an APK, which
need different signing), take a backup first: Settings, Backup & restore, Back up
now, and send the file somewhere safe. After reinstalling, Settings, Backup &
restore, Restore.

Play Protect may warn that the app is from an unknown source. That warning is
about the install route, not about the app; choose "Install anyway" if you got the
file from the developer.
